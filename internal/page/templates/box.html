ESM never updates itself on its own. An update takes a release only when its signature checks out with the key built into ESM and the binary's hash matches the signed list; the old binary is kept next to it as .previous. ESM then restarts through its service manager (esm service install); when nothing would start it again, the update asks first and ESM then has to be started by hand. On the box: esm update-self.
