Newest is the build of its channel that was installed last; point at a version to see its commit. A build a server has run is kept for a rollback (the newest few per server). Every file of every build was checked against its manifest when it was installed. Updating a server to another build is done from the server's Overview.

Where the build comes from

From a folder in the import folder

Folder

ESM reads local builds only from its import folder: imports in ESM's folder, unless build_import_dir in esm.json names another. The folder needs a manifest.json that lists every file with its SHA-256.
