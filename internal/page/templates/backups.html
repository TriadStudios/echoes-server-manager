Scheduled backups
{{if $v.Admin}}{{end}}

Scheduled backups run only while the server runs. ESM also always backs up before every update and before a restore; that cannot be turned off. A backup of a running server waits for its next world save, up to a set time; the list says when it did not see one. To keep copies off this box, copy the backups folder of the ESM root (see Box).
