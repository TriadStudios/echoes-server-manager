How automatic updates work

auto_update is set under Settings: off and install only show the newer build; restart updates a running server as soon as it has no players (it asks the query port), with a backup first and a roll back to the previous build when the new one does not get ready. A stopped server is never started by an update: its build is switched, and the next start checks it.
